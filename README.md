# 🎵 Relevé Musical

Application web d'analyse et de relevé automatique de morceaux audio.

## Fonctionnalités
- Détection de la tonalité
- Estimation du tempo (BPM)
- Grille d'accords mesure par mesure
- Extraction de la ligne de basse
- Export MIDI de la basse
